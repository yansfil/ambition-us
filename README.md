# poin 데모

poin은 사용자의 언어·반언어·비언어 신호를 읽어 망설임의 순간을 포착하고, 대화 중간에 작은 제안으로 개입해 "더 나은 다음 턴"을 함께 만드는 레이어다. 이 데모는 채팅 쇼핑 에이전트 위에 poin을 얹었다. 개입은 에이전트 말풍선이 아니라 커서를 따라다니는 poin 칩으로 나타난다.

## 실행

```bash
npm install
cp .env.local.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev                        # http://localhost:3000
```

- 에이전트 모델: 기본 `claude-haiku-5-5`. `POIN_AGENT_MODEL=sonnet`이면 `claude-sonnet-5-5`.
- poin 추론 모델: `claude-haiku-5-5`.
- 키는 서버 라우트에서만 읽는다. 클라이언트로 나가지 않는다.

## 구조

| 경로 | 내용 |
|---|---|
| `src/components/chat/`, `src/app/api/chat/` | 채팅 에이전트(도구: search_catalog, show_products, add_to_cart, checkout), 목 카탈로그 24개 |
| `src/poin/signals/`, `moments/`, `engine/`, `ui/` | 신호 수집 → 순간 감지(룰) → 추론(`/api/poin/infer`) → 칩 → 반응 → 결과 |
| `src/poin/panel/` | 운영 로그 패널(` 키로 토글), 세션 회고 |
| `src/poin/sense/` | 감지 모드(MediaPipe, 브라우저 안에서만 실행) |
| `src/poin/types.ts`, `store.ts`, `CONTRACTS.md` | 모듈 계약 |
| `design/board.html` | 시안 v4 |

UI 문구는 전부 `src/i18n/`에 있다. 영어로 바꿀 때는 같은 키로 파일을 추가한다.

## 순간 재현 방법

반응 키: `⌥1` 첫 번째 제안, `⌥2` 두 번째 제안, `Esc` 거절. 감지 모드가 켜져 있으면 끄덕이면 수락, 저으면 거절. 15초 동안 반응이 없으면 사라진다(무응답도 기록).

| 순간 | 재현 | 칩 예시 | 결과 |
|---|---|---|---|
| 요구 모호 | 첫 메시지를 쓰다 지우기를 두어 번 하고 2.5초 멈춤 | "먼저 두 가지만 짧게 여쭤볼까요?" | 에이전트가 추천 전에 질문 2개 |
| 비교 망설임 | 텍스트 추천이 온 뒤, 문단 사이를 마우스로 오가거나 같은 문단을 다시 읽거나 가격을 드래그 | "한눈에 보기 쉽게 정리해 드릴까요?" | ⌥1 표로 요약, ⌥2 사진 카드로 |
| 결정 직전 머뭇 | 상품 카드의 담기 버튼 위에 1초 머물고 누르지 않음(감지 모드면 찌푸림도 근거) | "가격이나 반품이 마음에 걸리세요?" | 수락: 가격·반품 답변, 거절: 더 싼 대안 |
| 다음 턴 제안 | 에이전트 응답이 끝난 뒤 5초 동안 아무것도 안 함 | "예산 안에서 하나만 골라 드릴까요?" | 에이전트 행동 또는 입력창 초안 채우기 |

판단 기준(확신도 임계 0.40, 체류 1초, 정지 2.5초)은 로그 패널 아래 슬라이더로 바꾼다. 쿨다운 15초, 세션당 최대 8회, 같은 종류를 연속 2번 거절·무시하면 그 종류만 2분 쉰다.

## 로그

- 개발: 클라이언트와 서버 로그가 `logs/poin-YYYYMMDD.jsonl` 한 파일로 모인다.
- 프로덕션: 클라이언트 로그는 이 탭의 sessionStorage에만, 서버 로그는 호스팅 런타임 로그(콘솔)에만 남는다.
- 로그 패널의 "내보내기"로 세션 JSON(트레이스·신호·로그)을 받을 수 있다.

## 개인정보

첫 방문 때 동의 모달로 무엇을 읽는지 알린다. 동의하지 않으면 poin 신호 읽기가 꺼진 채로 채팅만 쓸 수 있다. 카메라 영상은 브라우저 밖으로 나가지 않고 각도·수치만 쓴다. 결제는 연습용이다.

## 알려진 한계

- 공개 배포 시 API 호출 제한·인증이 없다.
- "다음 턴 제안"의 에이전트 지시문은 LLM이 쓰고 서버가 검증한다. 바꿔 말한 프롬프트 주입은 막지 못한다.
- 감지 모드의 찌푸림·시선 임계값은 실제 얼굴로 충분히 보정하지 않았다.
